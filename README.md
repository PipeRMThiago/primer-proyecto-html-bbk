# primer-proyecto-html-bbk
Primer proyecto del bootcamp BBK- The bridge basado en HTML y CSS

Para mi primer proyecto de HTML-CSS me motivó realizar una página web 
que invita a las personas a conocer las maravillas que ofrece Colombia.

Para la realización de este proyecto, fue necesario el Visual studio code 
en su versión 1.140.0, implementando lenguaje de marcas HTML5 y CSS3 para 
los estilos.

El archivo (carpeta) general contiene 2 carpetas, "img" para los archivos  
multimedia, en este caso solamente imagenes y otra "css" que contiene el arachivo
style.css de los estilos, además de 3 archivos HTML, para un total de 32 elementos.
